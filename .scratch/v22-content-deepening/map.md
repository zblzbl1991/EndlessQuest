# Wayfinder Map (wayfinder:map): EndlessQuest V2.2——内容深化包

## Destination

V2.1 之后的四项内容深化 + 一项本地化替代全部落地，游戏在"构筑深度 / 回访反馈 / 中后期新鲜感"三个维度补齐设计稿剩余承诺：

1. **闭关报告完整版**——击杀 / 装备获取与分解 / 秘境探索统计入离线报告（设计稿 §十一兑现）；
2. **祝福分系 Build 化（P1-d）**——祝福分 6 系扩到 30+、同系合成升阶、Build 协同词条（§九）；
3. **装备词条 V2（P1-e）**——词缀池 30+ 机制词条、品质体系扩展、自动分解（§十）；
4. **洞天福地**——化神解锁的**派驻配置层**（弟子入洞 → 宗门被动）；
5. **道祖榜（本地自比）**——替代排行榜/赛季：与自己历史最快通关对比，零后端。

终点判据：`npm test` 全绿；`simulate-pacing.ts` exit 0 基线不回退；各系统有单测断言真实生效；GUI 冒烟走通新交互。

## Notes

- 领域：挂机修仙 Incremental。设计事实以 `docs/superpowers/specs/2026-09-11-idle-incremental-v2-design.md` §九/§十/§十一为准；领域词汇见根目录 `CONTEXT.md`。
- **执行方式覆盖 wayfinder 默认（Plan, don't do）**：沿用 V2.1 先例（用户选定），规划后按序执行，每单实现+单测+`npm test` 全绿后 resolve。
- **用户锁定决策（2026-09-13 grill，四问）**：
  1. 组织 = 一张 map 全收四项，排行榜单独处置；
  2. 排行榜/赛季 = 砍掉真排行榜（纯前端单机，后端成本与定位不符），改为**本地自比**的"道祖榜"；
  3. 洞天福地 = **派驻配置层**而非设计稿的"第二生产层"（该生态位已被 V2.1 工单 07 仙界建筑线占掉）：弟子派驻洞天按资质获得宗门被动，补足"配置优于手操"支柱与化神期新鲜感；
  4. 执行顺序 = 闭关报告 → 祝福分系 → 装备词条 → 洞天福地；道祖榜无依赖可随时插入（实际排最后）。
- 关键事实（2026-09-13 核实）：`affixes.ts` 是**敌人**词缀（5 种），装备词缀在 `talentAffixes.ts`（约 6 种属性、上限 2 条）——P1-e 动的是后者；祝福现有约 13 种无系别字段；`offlineAccumulator` 已有资源/突破/炼制/税收/灵气短缺五类统计；ItemQuality 现为 5 档（common/spirit/immortal/divine/chaos），设计稿 §十 的 9 档方案需在工单内做映射决策（历史档兼容）。
- 战斗机制缺口（祝福六系 vs 引擎现状）：CombatEngine 已有元素亲和、主动技、暴击、灵宠实体；召唤/毒系可能缺实体与 dot 机制——工单 02 第一步做引擎盘点，六系定义按引擎能力调整（召唤系可考虑复用灵宠实体为"御兽系"）。
